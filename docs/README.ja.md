**画像や 3D アセットを、自分の PC で。ひとりでも、コーディングエージェントと一緒でも。**

Foundry は、ローカルで動く AI ワークフローを、手順に沿って進められるウィザードにまとめたツールです。使いやすい初期設定、プレビュー、結果の保存がそろっています。ComfyUI に慣れていなくても始められます。Pinokio のインストーラーなら、必要なソフトウェアや依存関係もまとめて設定できます。細かく調整したいときは、ComfyUI でノードグラフを開けます。

ゲーム用の小物やキャラクターのパーツ、髪、ガウシアンスプラット、3D プリント用の素材などを作れます。生成後は用途に合わせて結果を確認してください。メッシュの修正やリトポロジー、フィッティング、印刷の準備が必要な場合があります。

## 公式プロジェクトと Pinokio コミュニティ

オリジナルの Foundry は **mumblebox-gpt** が GitHub で管理しています。開発状況やリリースの内容、ダウンロードは公式リポジトリから確認できます。フォークや README のコピーを読んでいる場合も、以下のリンクから公式プロジェクトへ移動できます。 [公式 GitHub](https://github.com/mumblebox-gpt/mumblebox-foundry) · [公開リリース](https://github.com/mumblebox-gpt/mumblebox-foundry/releases)

Pinokio があるおかげで、ローカルツールのインストールや共有が手軽になりました。プロジェクトや感想を共有してくださる皆さん、そして cocktail peanut に感謝します。 [Pinokio の Foundry ページ](https://pinokio.co/apps/github-com-mumblebox-gpt-mumblebox-foundry)

## コーディングエージェントと使う

Foundry でアセットのたたき台を作るようエージェントに頼み、その結果を Blender などの 3D エディターで一緒に仕上げられます。

- **MCP で Foundry の機能を呼び出せます。** エージェントはワークフローや設定を確認し、処理の開始、進捗の確認、プレビューの確認、書き出しファイルの取得ができます。画面と同じサービスを使います。
- **付属スキルは使い方のガイドです。** ワークフローの選び方、入力やメモリの確認、結果の判断、次のツールへの引き渡しをサポートします。
- **生成はローカルで行います。** Foundry の処理を待つ間、エージェントは別の作業に進めます。人が同じ結果をウィザードで開き、確認することもできます。

繰り返しのモデリング作業を減らし、時間とエージェントのトークンを節約するのが狙いです。効果はアセットやワークフロー、仕上げにかかる手間によって変わります。 [MCP と付属スキルの設定ガイド](AGENT-SETUP.md)

| **多視点** | 対応する Qwen または FLUX で 4 方向の画像を作って確認し、Pixal3D で再構成。Hi3D と TRELLIS.2 で仕上げます。 | 人型キャラクターの出発点に。乗り物や小物、クリーチャー向けの設定は改良中です。 |

| **CCORE テキスト** | 文章からスタイルのある小物を作ります。編集できる例文 12 種、Qwen による記述の補強、3D プレビュー、GLB の書き出しが使えます。 | 道具や家具など、単体の小物を作るときに。 |

## 始め方

1. [Pinokio](https://pinokio.co/) をインストールし、[Foundry のインストール手順](PINOKIO.md)に沿ってリポジトリを追加します。
2. Pinokio で **Install**、**Start Foundry**、**Open Foundry** の順に選びます。
3. **単一画像またはテキスト**を開きます。画像をアップロードするか、画面へドラッグ、ウェブカメラで撮影、ギャラリーから選択のいずれかで用意します。説明文から画像を作ることもできます。
4. プレビューを確認して、欲しい出力を選びます。**Rocket Mode** では任意の確認で止まらず、選んだ残りの処理を続けられます。

既存の ComfyUI に入れる場合は、[手動インストール手順](../INSTALL.md)に従ってから、`Mumblebox 3D Asset Foundry.json` を開きます。インストールではソフトウェアを準備します。足りないモデルの重みは、必要になったワークフローの初回実行時に準備します。モデル、作業ファイル、結果用のディスク容量を確保してください。

## 確認と書き出し

使える書き出しはワークフローによって異なります。GLB、FBX、OBJ、BLEND、STL、SPZ、テクスチャ、プレビュー、ZIP などから選べます。高詳細メッシュや軽量メッシュに UV やベイクしたテクスチャを含めることもできます。

**四角面はオプションです。** 単一画像と多視点では CPU の QuadriFlow、Instant Meshes や NVIDIA CUDA の CyberRemesher を選べます。QuadriFlow の処理中に CPU 使用率が一時的に高くなるのは正常で、時間がかかることもあります。四角面を選ばなくてもテクスチャ付きの三角面メッシュは作成できます。GLB のプレビューは三角面を使います。対応する編集用形式では四角面を保持できます。

アニメーション用のトポロジー、印刷や当たり判定用の形状、材質は、実際に使うエディターやエンジンで確認してください。HairDeck の静的 GLB と揺れものボーン付き VRM は別々の出力です。首振りプレビューで髪の動きを確認できます。Garment Particles のフィッティングやドレープは実験的な機能です。

ZIP には選択したファイル、README、測定値、チェックサム、出典、適用される注意事項が含まれます。通常のパッケージには、非公開の参考画像、プロンプト、作業ファイルは入りません。履歴で保存済みの結果を確認できます。**履歴 → 動画**では、個別に保存した動画を再生、ダウンロード、削除できます。

## 言語と表示

画面上部または設定から表示言語を選べます。表示はその場で変わり、入力した文章や参考画像、プレビュー、処理中のジョブはそのまま使えます。

表示言語と生成モデルに渡す言語は別です。プロンプトやモデル向けの指示は入力したとおりに使います。生成に適した言語は、使うモデルの案内を確認してください。

CCORE の作者は英語のプロンプトを推奨しています。内蔵の例文は表示言語に合わせて入力欄に入ります。**英語に翻訳**でローカルの Qwen を使い、結果を確認してから生成できます。Q4 は GPU メモリの消費を抑えたいときのおすすめです。Q8 は数値精度が高い設定ですが、翻訳の質が必ず上がるわけではありません。GPU メモリに収まらない場合も、入力した説明は残ります。**説明を充実させる**は、創作上の細部を追加できる別の機能です。

**テーマ**でライト表示とダーク表示を選べます。**文字サイズ**は標準、112%、125%、150%、175%、200% から選べます。

## Foundry と付属スキルを更新する

新しい版では、ワークフローや修正、エージェント向けのガイドが増えることがあります。しばらく使っていなかったときなどは、画面上部の更新表示を確認してください。Pinokio では実行中の作業を終えてから **Update** を選びます。ComfyUI に手動で入れた場合は[インストール手順](../INSTALL.md)の更新方法に従ってください。

Foundry を更新すると同梱のスキルも更新されます。**エージェントのスキルフォルダーにコピーして使っている場合は、コピーも更新してください。** スキルには、稼働中のアプリのバージョンや機能、互換性、更新の有無を調べ、不一致や更新を利用者の言語で知らせるように案内しています。

## ハードウェア、空き容量、ライセンス

現在は **Windows / NVIDIA 向けのプレビュー版**です。参考環境は RTX 4080 SUPER、VRAM 16 GB、RAM 64 GB です。必要な容量はワークフローによって異なります。CCORE は GPU メモリの空き容量を確認し、選んだ組み合わせが収まらない場合は、負荷を抑えた選択肢を提示します。

設定でモデルを管理したり、キャッシュを消去したりできます。消す前にファイルの一覧をご確認ください。ワークフローで必要になった公開モデルは再取得できます。

Foundry 独自のコードは **Apache-2.0** です。モデル、重み、外部ツールにはそれぞれの利用条件があります。 [第三者の利用条件と商用利用の注意事項](../THIRD-PARTY.md)
