**Foundry 版本 0.1.0-preview.30**

[English](../README.md) · [简体中文](README.zh-CN.md) · [Español (Latinoamérica)](README.es-419.md) · [Français](README.fr.md) · [Português (Brasil)](README.pt-BR.md) · [Deutsch](README.de.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [हिन्दी](README.hi.md)

**在自己的电脑上制作图片和 3D 资产，也可以让编程智能体一起帮忙。**

Foundry 把实用的 AI 工作流整理成一步步的向导，提供合适的默认设置、预览和结果保存。即使不了解 ComfyUI，也能开始使用。Pinokio 安装器会配置软件和依赖；需要更深入地控制流程时，你也可以打开底层节点图。

用它探索游戏道具、角色部件、头发、高斯泼溅，以及创意项目或 3D 打印所需的资产。生成后仍应按实际用途检查，部分结果还需要修改、重拓扑、适配或打印准备。

## 给编程智能体一个好起点

可以让智能体先用 Foundry 生成起始资产，再一起到 Blender 或其他 3D 编辑器里继续完善。

- **MCP 提供工具接口。** 智能体可以查询工作流和设置、提交任务、查看进度、检查预览并获取导出文件，使用的是与图形界面相同的服务。
- **配套技能提供使用指引。** 帮助智能体选择合适的流程，理解输入要求及内存、显存限制，检查结果，再把资产交给下一个工具。
- **生成在本机进行。** Foundry 处理任务时，智能体可以继续做其他独立工作。你也能在向导里查看结果，接着处理同一份已保存的内容。

我们的目标是减少重复建模工作，节省时间和智能体消耗的 token。实际能省多少，取决于资产类型、流程和后续加工量。请先阅读 [MCP 与配套技能设置说明](AGENT-SETUP.md)。配套技能还在持续完善，我们会结合真实项目和社区反馈继续改进。

## 选择适合的工作流

| 工作流 | 可以得到什么 | 什么时候适合用 |
| --- | --- | --- |
| **单图或文字** | 一张图片经过 Pixal3D 生成几何、Hi3D 细化、清理、TRELLIS.2 纹理处理，再按所选格式导出。也能在向导里用文字创建参考图。 | 最直接的网格生成方式，步骤和模型较少。建议从主体清晰的四分之三视角开始。 |
| **多视图（Turnaround）** | 用支持的 Qwen 或 FLUX 模型生成并检查四个视角，再由 Pixal3D 重建，接着用 Hi3D 和 TRELLIS.2 完成后续处理。 | 人形角色是较好的起点。车辆、道具和生物的流程仍在改进。 |
| **3D 引导（3D-Guided）** | Pixal3D 代理网格结合 Blender 的测量视角、MoGe 2 估计和 Qwen 引导，完成重建和后续处理。 | 适合需要选择并检查视角的独立物件，处理步骤更多。 |
| **Splat & Solid** | Sperid Labs 的 Idol 生成细致的高斯泼溅，Foundry 另行提供清理后的配套网格，并可选用 Hi3D 细化。 | 兼顾丰富外观和轻量几何，可查看环绕预览和网格对比。 |
| **环绕视频转网格** | 先生成 H3 环绕视频，检查对齐后的视图，再用 Pixal3D 重建，最后由 Hi3D 和 TRELLIS.2 完成资产。 | 适合在建模前检查不同角度，排除模糊或变形的画面。 |
| **环绕重建：网格与高斯泼溅** | 用同一段环绕视频生成带纹理的网格和对齐的高斯泼溅。使用联动视角预览，导出配对文件或混合 MP4。 | 适合需要可编辑网格，同时希望保留随视角变化的细节。 |
| **虚拟转台** | 用 H3 生成环绕视频，再用 Meshroom 或 COLMAP + OpenMVS 重建。 | 适合用稳定的生成视频尝试摄影测量。 |
| **CCORE 文字生成道具** | 通过文字描述生成程序化的风格化道具，提供 12 个可编辑示例、可选的本地 Qwen 描述增强、3D 预览和 GLB 导出。 | 工具、家具等单个游戏道具。 |
| **CCORE 图片 + 文字** | 一张图片和文字描述交给 CCORE 的视觉投影器与生成流程。也能在向导里创建参考图。 | 保留或修改照片、草图、渲染图中的特征。 |
| **HairDeck** | 风格化发片、多个方案、预处理拼图、位置适配、材质、可选弹簧骨链、动态预览和所选的 GLB/VRM 导出。 | 清晰的发型参考图，由 HairDeck 及 FengLairh 的 ComfyUI 集成提供支持。 |
| **Garment Particles — 实验性** | 服装生成、作者的编辑工具、缝制纸样检查、网格准备、实验性 Blender 垂坠模拟和角色交接。 | 探索服装设计，穿着适配与变形仍需仔细检查和进一步加工。 |
| **创建图片** | 单张图片或正反面参考图，支持编辑、兼容的 LoRA 和图库保存。 | 为其他向导准备参考图，也可以只保留图片。 |

每种工作流都有自己的向导和独立管理的节点图分支。标为“即将推出”的卡片属于后续计划。

## 开始制作

1. 安装 [Pinokio](https://pinokio.co/)，按照 [Foundry 安装说明](PINOKIO.md) 添加此仓库。
2. 依次选择 **Install**（安装）、**Start Foundry**（启动）和 **Open Foundry**（打开界面）。这些是 Pinokio 启动器里的按钮名称。
3. 打开“单图或文字”向导。上传或拖入图片、用摄像头拍照、从图库选择，或根据描述创建一张图片。
4. 检查预览并选择输出。**火箭模式**可以连续执行剩余的已选步骤，跳过可选的中途检查。

已有 ComfyUI 的用户可以按照 [INSTALL.md](../INSTALL.md) 手动安装，再打开 Mumblebox 3D Asset Foundry.json。安装阶段准备软件；首次运行所选工作流时，会在处理前下载缺少的模型权重。打开 Foundry 不会下载整个模型库。请为权重、临时文件和输出预留磁盘空间。

## 检查与导出

可用格式取决于工作流。向导会列出所支持的 GLB、FBX、OBJ、BLEND、STL、SPZ、纹理、预览和 ZIP 等选项。高细节网格和减面网格可包含 UV 及烘焙贴图。

**四边面是可选项。** “单图或文字”和“多视图”提供 CPU 上运行的 QuadriFlow、Instant Meshes，以及使用 NVIDIA CUDA 的 CyberRemesher。每个求解器都有高级设置和说明。QuadriFlow 运行时 CPU 占用突然升高属于正常现象，处理可能需要一些时间。关闭四边面后仍会生成带纹理的三角面资产。GLB 预览使用三角面，编辑用的导出文件则保留所支持的四边面。

请在目标编辑器或引擎中检查变形拓扑、打印几何、碰撞和材质。HairDeck 的静态 GLB 与带弹簧骨的 VRM 是不同输出；转头预览用于展示头发动态。Garment Particles 仍属实验性功能，尤其是角色适配和垂坠模拟。

资产包包含所选文件、README、测量数据、校验和、来源记录及适用声明。普通资产包不包含私有源图片、提示词和工作文件。已保存结果可以从历史记录中查看，并恢复该流程支持的操作。在**历史记录 → 视频**中，可以播放、下载或删除单独保存的工作流视频。

## 语言与阅读设置

在顶部或设置中选择界面语言。切换语言会使用本地语言资源直接更新界面，已填写的内容、参考图、预览和正在运行的任务都会保留。

界面语言与生成提示词的语言分别处理。Foundry 会保留你的提示词和模型指令。选择提示词的语言时，请参考所用模型的说明。

CCORE 作者建议使用英文提示词生成资产。内置示例会随界面语言显示，并填入相应语言的描述。你可以点击 **翻译成英文**，让本地 Qwen 助手翻译描述，检查后再生成。可选择显存占用较少的 Q4，或数值精度更高的 Q8。建议先用 Q4；Q8 并不保证译文更好。翻译需要所选模型能装入 GPU 显存，装不下时会保留原文并提示你调整选择。翻译会保留设计内容；**增强描述**是另一个可补充创意细节的选项。

“主题”可切换明暗外观。“字体”提供默认、112%、125%、150%、175% 和 200% 大小。需要更多控制时，可以展开高级设置。

## 让 Foundry 和配套技能保持更新

新版本可能带来新的工作流、问题修复和更好的智能体使用指引。建议定期检查更新，尤其是在一段时间后重新使用时。

顶部会显示更新状态。Pinokio 用户应等待当前任务结束，再使用正常的 **Update** 操作。独立 ComfyUI 用户请按照 [INSTALL.md](../INSTALL.md) 的更新说明操作。

更新 Foundry 会更新它附带的技能。**如果你把技能复制到了智能体的技能目录，也需要刷新那份副本。** 在这种安装方式下，应用更新和技能副本更新是两件事。

配套技能会提醒智能体读取当前应用版本和实际可用功能，检查兼容信息与待安装更新，并用你的语言说明发现的不匹配或更新提示。具体可用设置始终以运行中的应用返回的信息为准。

## 硬件、存储与使用条款

目前是 **Windows / NVIDIA 预览版**。参考机器配备 RTX 4080 SUPER、16 GB 显存和 64 GB 内存。不同工作流的资源需求不同，这套配置不代表最低硬件保证。CCORE 会检查显存，在请求的组合装不下时提供支持的较小设置。

设置中提供已安装模型管理和先预览再清理的缓存功能。工作流需要某个已发布模型时，会重新准备缺少的权重。清理缓存或移除权重前，请核对列出的文件。

Foundry 原创代码采用 **Apache-2.0** 许可证。模型、权重和其他工具各自保留原有条款，尤其在商用前请阅读 [第三方声明](../THIRD-PARTY.md)。
