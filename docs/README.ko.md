**Foundry 버전 0.1.0-preview.30**

**내 PC에서 이미지와 3D 에셋을 만들어 보세요. 혼자 작업해도, 코딩 에이전트와 함께해도 좋아요.**

Foundry는 로컬 AI 작업을 단계별 워크플로로 묶어 둔 도구입니다. 바로 쓸 수 있는 기본 설정과 미리 보기, 결과 저장을 지원합니다. ComfyUI를 처음 써도 시작할 수 있어요. Pinokio로 설치하면 필요한 소프트웨어와 의존성도 함께 설정됩니다. 더 세밀하게 조정하고 싶다면 ComfyUI에서 노드 그래프를 열 수 있습니다.

게임 소품, 캐릭터 파츠, 머리카락, 가우시안 스플랫, 3D 프린팅용 모델 등을 만들어 보세요. 결과를 어디에 쓸지에 맞춰 확인하고, 필요하면 메시를 다듬거나 리토폴로지를 거치거나 캐릭터에 맞추거나 출력용으로 손봐 주세요.

## 코딩 에이전트와 함께 쓰기

에이전트에게 Foundry로 기본 에셋을 만들어 달라고 한 뒤 Blender나 다른 3D 편집기에서 함께 다듬을 수 있습니다.

- **MCP로 Foundry 기능을 호출합니다.** 에이전트가 워크플로와 설정을 확인하고, 작업을 시작하고, 진행 상황과 미리 보기를 확인하고, 내보낸 파일을 받을 수 있습니다. 앱 화면과 같은 서비스를 사용합니다.
- **동봉된 스킬이 사용법을 안내합니다.** 워크플로 선택, 입력과 메모리 확인, 결과 검토, 다음 도구로 넘겨주는 과정까지 도와줍니다.
- **생성은 내 PC에서 진행됩니다.** Foundry가 계산하는 동안 에이전트는 다른 작업을 할 수 있습니다. 같은 결과를 앱에서 직접 열어 확인하고 이어서 작업할 수도 있습니다.

반복되는 모델링을 줄여 시간과 에이전트 토큰을 아끼는 것이 목표입니다. 어느 정도 절약되는지는 에셋과 워크플로, 필요한 마무리 작업에 따라 달라집니다. [MCP와 동봉 스킬 설정](AGENT-SETUP.md)

| **회전 영상과 스플랫** | 같은 회전 영상으로 텍스처를 입힌 메시와 위치를 맞춘 가우시안 스플랫을 만들어요. 연동 카메라로 비교하고 한 쌍으로 내보내거나 합성 MP4를 만들 수 있어요. | 편집 가능한 메시와 보는 각도에 따라 달라지는 디테일이 함께 필요할 때 좋아요. |

워크플로마다 전용 마법사와 독립된 노드 그래프 구역이 있습니다. **추가 예정** 카드에는 앞으로 개발할 내용이 표시됩니다.

## 시작하기

1. [Pinokio](https://pinokio.co/)를 설치하고 [Foundry 설치 안내](PINOKIO.md)에 따라 저장소를 추가합니다.
2. **Install**, **Start Foundry**, **Open Foundry** 순서로 선택합니다.
3. **단일 이미지 또는 텍스트**를 엽니다. 파일을 올리거나 끌어다 놓고, 웹캠으로 찍거나 갤러리에서 골라도 됩니다. 설명으로 이미지를 바로 만들 수도 있습니다.
4. 미리 보기를 확인하고 필요한 결과를 고릅니다. **Rocket Mode**는 중간에 직접 확인하는 선택 단계를 건너뛰고 선택한 나머지 작업을 실행합니다.

기존 ComfyUI에 설치하려면 [수동 설치 안내](../INSTALL.md)를 따른 뒤 `Mumblebox 3D Asset Foundry.json`을 여세요. 설치할 때는 소프트웨어를 준비합니다. 모델 파일이 부족하면 해당 워크플로를 처음 사용할 때 받습니다. 모델, 작업 파일, 결과물에 필요한 디스크 공간을 확보해 주세요.

## 미리 보기와 내보내기

지원되는 출력은 워크플로마다 다릅니다. GLB, FBX, OBJ, BLEND, STL, SPZ와 텍스처, 미리 보기, ZIP 등 필요한 항목을 고를 수 있습니다. 고해상도 메시와 간소화된 메시에는 UV와 베이크한 텍스처를 포함할 수 있습니다.

**쿼드(사각형 면)는 선택 사항입니다.** 단일 이미지와 다중 시점에서는 CPU의 QuadriFlow와 Instant Meshes, NVIDIA CUDA의 CyberRemesher를 쓸 수 있습니다. 각 솔버의 상세 설정과 설명은 마법사에 있습니다. QuadriFlow 실행 중 CPU 사용량이 치솟는 것은 정상이며 처리에 시간이 걸릴 수 있습니다. 쿼드를 끄면 텍스처가 적용된 삼각형 메시를 얻습니다. GLB 미리 보기 역시 삼각형으로 표시하며, 지원되는 편집용 형식에는 쿼드 면이 유지됩니다.

사용할 편집기나 엔진에서 애니메이션용 토폴로지, 인쇄와 충돌용 메시, 재질을 살펴보세요. HairDeck의 정적 GLB와 스프링 본이 든 VRM은 각각 별도의 파일입니다. 회전 미리 보기에서 머리카락 움직임을 확인할 수 있습니다. Garment Particles의 캐릭터 맞춤과 드레이핑은 실험 기능입니다.

ZIP에는 선택한 파일, README, 측정 정보, 체크섬, 출처와 관련 안내가 들어갑니다. 일반 패키지에서는 비공개 참고 이미지, 프롬프트, 작업 파일을 제외합니다. 저장된 결과는 기록에서 다시 열 수 있습니다. **기록 → 동영상**에서 따로 저장한 영상을 재생하거나 다운로드하거나 삭제할 수 있습니다.

## 언어와 읽기 편한 화면

상단이나 설정에서 표시 언어를 고르세요. 화면의 문구가 바로 바뀌며, 입력한 내용, 참고 이미지, 미리 보기와 진행 중인 작업은 그대로 유지됩니다.

화면 언어와 모델에 입력하는 언어는 각각 정할 수 있습니다. Foundry는 프롬프트와 모델에 보내는 지시를 그대로 사용합니다. 생성에 적합한 입력 언어는 해당 모델의 안내를 참고하세요.

CCORE 제작자는 영어 프롬프트를 권장합니다. 기본 예시는 선택한 언어로 입력됩니다. **영어로 번역**을 누르면 로컬 Qwen이 설명을 번역합니다. 내용을 확인한 다음 생성을 시작하세요. Q4는 GPU 메모리를 적게 쓰는 기본 추천 옵션이고, Q8은 수치 정밀도가 높습니다. 번역 품질이 항상 좋아지는 것은 아니에요. 모델이 GPU 메모리에 들어가지 않으면 작성한 설명을 그대로 보존합니다. **설명 보강**은 창의적인 디테일을 더해 주는 별도의 기능입니다.

**테마**에서 밝게 또는 어둡게 바꾸고, **글자 크기**에서 기본, 112%, 125%, 150%, 175%, 200%를 선택할 수 있습니다.

## Foundry와 스킬을 최신으로 유지하기

새 버전에는 워크플로와 수정 사항, 에이전트용 사용 안내가 추가됩니다. 오랜만에 사용할 때는 특히 상단의 업데이트 표시를 확인하세요. Pinokio에서는 진행 중인 작업이 끝난 뒤 정상 **Update** 기능을 사용하세요. 단독 ComfyUI 설치는 [수동 설치 안내](../INSTALL.md)를 따르세요.

Foundry를 업데이트하면 동봉 스킬도 업데이트됩니다. **에이전트의 스킬 폴더에 복사해 두었다면 복사본도 별도로 업데이트해 주세요.** 스킬은 에이전트가 현재 앱 버전과 실제 기능, 호환성, 업데이트 여부를 확인하고 차이가 있으면 사용자의 언어로 설명하도록 안내합니다.

## 하드웨어, 저장 공간, 사용 조건

현재는 **Windows / NVIDIA 프리뷰**입니다. RTX 4080 SUPER와 VRAM 16 GB, RAM 64 GB 환경을 기준으로 확인했습니다. 필요한 자원은 워크플로에 따라 달라집니다. CCORE는 사용할 수 있는 GPU 메모리를 확인하고, 선택한 조합이 들어가지 않으면 더 작은 설정을 제안합니다.

설정에서 설치된 모델과 캐시를 관리할 수 있습니다. 삭제하기 전에 나열된 파일을 확인하세요. 워크플로에서 공개된 모델이 다시 필요하면 재다운로드할 수 있습니다.

Foundry의 자체 코드는 **Apache-2.0**입니다. 모델, 가중치와 외부 도구는 각자의 사용 조건을 따릅니다. [타사 라이선스와 상업적 이용 안내](../THIRD-PARTY.md)
